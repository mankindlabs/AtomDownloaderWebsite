# Atom Downloader — by Mankind

A responsive React + Vite product page using the supplied Atom artwork. The reference project and original PNG assets remain unchanged.

## Local development

Run `npm install` and `npm run dev` from this directory.

## Production

Run `npm run build`. Deploy the generated `dist` directory to a static host.

## Installer URL

Set `VITE_DOWNLOAD_URL` to the official HTTPS installer URL in your deployment environment (or a local `.env` file), then rebuild. Without an HTTP(S) URL, every download button opens an accessible availability dialog rather than starting a nonexistent download.

## Included

Responsive navigation, optimized WebP artwork, keyboard-accessible native download dialog, reduced-motion support, skip navigation, page metadata, lazy-loaded below-the-fold art, and prominent Mac download calls to action. Google Fonts supplies Manrope and DM Sans; system fonts are used if unavailable.
