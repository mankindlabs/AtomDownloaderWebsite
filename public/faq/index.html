Atom IDM FAQ

Straight answers about the IDM for Mac.

Is Atom IDM the IDM for Mac?

Yes. Atom IDM (Atom Downloader) is an Internet Download Manager built for macOS. It splits files into parts and downloads them in parallel, resumes after Wi-Fi drops, and checks every file before you open it.

Does Atom IDM run on Apple Silicon and Intel Macs?

Yes. There is a native Apple Silicon build and a Universal build for Intel Macs. Both are signed and notarized by Apple.

Does Atom IDM resume broken downloads?

Yes. If your connection drops, Atom IDM waits for the network to come back and carries on from where it stopped, without starting over.

Is Atom IDM free?

There is a free version that downloads one file at a time. Pro ($25) and Ultra ($39.99) are one-time purchases — no subscription.

What is the difference between Pro and Ultra?

Pro unlocks many downloads at once plus Hugging Face and GitHub repositories. Ultra adds brew, npm and pip installs. Both are pay once, keep forever.

Is Atom IDM safe?

Every download gets a security check before it is marked ready, and the app is signed and notarized by Apple.
